# Vendure Admin App Starter

An open-source **Expo / React Native** starter for a Vendure admin mobile app — the mobile
counterpart of the [Vendure](https://vendure.io) web admin dashboard. It speaks the standard
Vendure **Admin GraphQL API** and works against any Vendure server.

> 🚧 Work in progress — see the epic issue for status. Full setup and architecture docs land with the first feature PR.
